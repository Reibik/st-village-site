# Разработка ST VILLAGE

## Ветки

- `main` — стабильная версия, которая автоматически публикуется на основном сайте.
- `dev` — интеграционная ветка для разработки и общей проверки новых функций.

## Рабочий процесс

1. Новые изменения начинаются от актуальной ветки `dev`.
2. Перед отправкой выполняется `pnpm release:check`.
3. Изменения публикуются в `dev` и проверяются без переключения production-сайта.
4. После подтверждения создаётся pull request из `dev` в `main`.
5. В `main` попадают только изменения с успешной автоматической проверкой.

Для крупных независимых функций можно создавать короткоживущие ветки от `dev`, а затем объединять их обратно в `dev`.

# ST VILLAGE v1.3.0 — Фирменная орбита

3 октября 2026 года. Основной сайт: https://stvillage.top/

## Что изменилось

- Главная получила новый дизайн «Фирменная орбита»: фирменный маскот, мягкая анимация, более свободная композиция и один основной акцент на пробном доступе.
- Условия пробного периода видны сразу: 1 день, 5 ГБ, 1 устройство, Германия / Польша / Швеция. Белые списки доступны только на платных тарифах.
- Личный кабинет остаётся центром управления подпиской. Начало работы объясняется тремя шагами: активировать доступ, установить Happ или INCY, добавить подписку.
- На главной отображаются два компактных анонса; полные новости с Telegram-разметкой и вложениями остаются на странице «Новости».
- Исправлены ссылки без протокола, вложенные спойлеры в анонсах, обновление компактной ленты и переход к выбранной публикации.
- Мониторинг учитывает активные инциденты и устаревшие данные. Страны формируются из реальных данных, автоматические маршруты не выдаются за отдельную страну; добавлен SVG-флаг Албании.
- Купоны временно закрыты: меню и футер показывают «Скоро», прямой адрес — уведомление. Выдача через API отключена, страница исключена из sitemap и индексации.
- Сохранены реальные тарифы, новостной бот, кабинет и чат поддержки Jivo. Структура платёжного сервиса не менялась.
- Усилена защита служебных API бота: чрезмерно большие запросы отклоняются без полного чтения потока, подписи и UTF-8 сохраняются.

## Проверки

В релизную проверку входят сборка, lint, TypeScript, ограничения веса изображений, серверные/unit-тесты и браузерные сценарии для desktop/mobile. Проверяются светлая тема, клавиатурная навигация, reduced motion и экран 320 px.

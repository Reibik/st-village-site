# ST VILLAGE

Публичный интерфейс цифровой экосистемы «Технологии • Сервисы • Возможности».

## Реализовано на первом этапе

- адаптивная главная страница с тёмной и светлой темами;
- отдельные страницы тарифов, подключения, статуса, новостей и поддержки;
- интерактивный мастер подключения для шести платформ;
- честные empty/error states для ещё не подключённых источников данных;
- экран будущей Telegram-авторизации без передачи секретов клиенту;
- sitemap, robots, manifest, Open Graph и системные страницы 404/500;
- health endpoints для приложения, базы и Remnawave;
- строгая типизация, линтинг и серверные render/API-тесты.

## Архитектурное направление

Проект развивается как модульный монолит на Next.js с App Router. UI находится в `app` и `src/components`, продуктовые сценарии — в `src/features`, контент и безопасные временные значения — в `src/config`. Следующие этапы добавят серверные модули авторизации, PostgreSQL + Prisma, личный кабинет, адаптеры Remnawave и платежей, административную панель и VPS-контур.

Внешние интеграции всегда вызываются только с сервера. Отсутствующие API не подменяются случайными числами или фиктивными записями.

## Локальный запуск

1. Установить Node.js 22.13+ и pnpm.
2. Скопировать `.env.example` в `.env` и заполнить только доступные значения.
3. Выполнить `pnpm install`.
4. Выполнить `pnpm dev`.

Перед production-запуском обязательно настроить реальный домен, Telegram-бота, базу данных и внешние интеграции. Юридические документы требуют проверки и заполнения реквизитов.

# Чек-лист релиза ST VILLAGE

## Перед публикацией

- [ ] `pnpm install --frozen-lockfile` завершается без изменений lock-файла.
- [ ] `pnpm release:check` проходит полностью.
- [ ] В рабочей копии нет секретов, временных файлов и незапланированных изменений.
- [ ] `.env.example` содержит все необходимые ключи без реальных токенов.
- [ ] Версия в `package.json` и `CHANGELOG.md` совпадает.
- [ ] Проверены главная, тарифы, подключение, статус, новости, поддержка и юридические страницы.

## После публикации

- [ ] `/api/health` отвечает `200` и `status: ok`.
- [ ] `/api/version` показывает текущий номер релиза.
- [ ] `/api/pricing` возвращает тарифы или последнюю подтверждённую выгрузку.
- [ ] `/api/status` возвращает безопасную сводку без внутренних адресов и токенов.
- [ ] `robots.txt`, `sitemap.xml`, manifest и social-preview доступны извне.
- [ ] На основном домене присутствуют security headers.
- [ ] Автоматический деплой сохранил возможность отката на предыдущий релиз.

## Откат

Если health-проверка новой сборки не проходит, VPS автоматически возвращает предыдущий рабочий релиз. При ручном откате нужно переключить `/opt/st-village-site/current` на проверенный каталог в `/opt/st-village-site/releases`, перезапустить `st-village-site.service` и повторить проверки этого списка.
